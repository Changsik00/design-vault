## 5. 학원 신규 등록 Attribution

### 5.1 채널 비중 가설 (1년차)

```
지인 추천         40% (기존)
YouTube 채널 ⭐    25% (Academy 효과)
학원 홈페이지     15%
광고              10%
기타              10%
```

### 5.2 검증 방법

- 입학 폼에 "어떻게 알게 됐나요?" 필수 입력
- 6개월 attribution 추적
- YouTube attribution ≥ 15% 달성 시 가설 검증

### 5.3 사업 의미

Academy 가 단순 비용이 아닌 **신규 등록 채널** 로 작동하면:

```
학원장 ROI 계산
  Pro 290K/월 - HyperFrames + 운영비 100K = 190K 마진 부담
  but YouTube 신규 등록 1명 = 학원당 평균 20만원/월 × 6개월 = 120만원
  → 6개월에 1명만 YouTube 로 들어와도 ROI 흑자
```

→ **학원장 의사결정에서 "비용" 이 아니라 "마케팅 채널 투자"** 로 인식되는 첫 SaaS.

## 7. Customer Acquisition

### Phase 별 채널

| Phase | 학원 확보 채널 |
|---|---|
| v0.1 (파일럿 2) | 지인·인맥 학원 직접 onboarding |
| v0.5 (파일럿 10) | 1~2호 학원 케이스 스터디 + 학원장 커뮤니티 (네카·맘카페) |
| v1.0 (30) | 학원장 단톡 / 학원 박람회 / 학원 채널 본인 노출 (own dogfooding) |
| v2.0 (100) | YouTube 채널 운영 사례 영상 + 학원장 인플루언서 + 학원장 컨퍼런스 |
| v3.0+ | Enterprise 본사 직접 영업 + 채널 파트너 |

### 핵심 metric

- CAC (Customer Acquisition Cost): 파일럿 단계 한 학원당 ~10만원 미만 목표
- LTV (Customer Lifetime Value): Pro 학원 평균 18개월 가정 → ~520만원
- LTV/CAC: 목표 ≥ 5
