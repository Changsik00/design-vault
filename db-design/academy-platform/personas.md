# 페르소나

> 작성일: 2026-05-23
> 4 페르소나 통합: 학원장 / 강사 / 학생 / 학부모.
> 각각 v0.1 MVP 시점 가치 + Phase 별 확장 명시.

---

## 1. 학원장 (Director)

> 학원의 모든 운영을 책임지는 최고 사용자. 본 제품의 **주 사용자**. 학원 YouTube 채널의 편집장, 강사 평가의 최종 결재자.

### 1.1 기본 프로필

| 항목 | 내용 |
|---|---|
| 역할 | 학원장 (대표자 / 사업자 본인) |
| 권한 | `DIRECTOR` — 본인 학원 모든 리소스 admin + YouTube 채널 admin |
| 주요 접점 | Vite SPA (학원장 화면) + 모바일 브라우저 + 카카오 알림톡 |
| 학원 규모 | Basic 30~100명 / Pro 100~300명 / Enterprise 300+명 |

### 1.2 Jobs-to-be-Done

1. **수업이 끝나면 자동으로 학원 채널이 자란다** — 마케팅 자산 자동 축적
2. **강사를 객관적으로 평가한다** — 평점 + 업로드 이행률 + 조회수 통합 (v1.0)
3. **학생 이탈을 사전 감지한다** (v1.0+)
4. **학원 RAG 로 학원 자산을 자연어 질의** ("이번 달 약점 단원?" — v0.5)
5. **강사 스케줄을 픽스한다** — 강사 요청 → 원장 승인 워크플로 (v1.0)
6. **5분 안에 학원 상태 파악** — 운영 대시보드 (v0.5)
7. **하위 평가 강사를 조기 식별한다** (v1.0+)

### 1.3 페인포인트

| # | 문제 | 심각도 |
|---|---|---|
| 1 | 학원 홍보 영상 만들 시간/예산 없음 | Critical |
| 2 | 강사가 수업 후 자료를 안 올림 | Critical |
| 3 | 학원장이 출근하지 않으면 학원 상태 모름 | High |
| 4 | 강사 인센티브 산정에 객관 근거 부족 | High |
| 5 | 학원 채널 운영 인력 없음 | High |
| 6 | 학생 이탈을 사후에야 인지 | Critical |
| 7 | 학부모가 "우리 아이가 뭐 배우는지" 못 봄 | High |
| 8 | 강사 스케줄 협상이 카톡으로만 흐름 | Medium |

### 1.4 Needs (Phase 별)

**v0.1 MVP**
- YouTube 채널 OAuth 연결 (최초 1회)
- 자동 업로드 정책 설정 (수동 검수 default)
- 영상 검수 화면 (썸네일·제목·설명 미리보기 → 승인/반려)
- 강사별 trust_relationship 부여 (자동 publish / view 권한)

**v0.5**
- 운영 대시보드 5 P0 화면 (오늘 수업 / 출결 / 알림 / 데이터 누적 / X2 토글)
- RAG 자연어 질의 채팅
- 학생 면담 prep 자동 생성
- 강사 자료 공유 정책 관리

**v1.0**
- 강사 평가 5축 대시보드 (평점·업로드 이행률·완주율·RAG 참조·조회수)
- 스케줄 픽스 워크플로
- 채널 성장 리포트 (월 구독자/조회수/attribution)

**v2.0+**
- 본사 통합 채널 (Enterprise)
- 학원 간 익명 벤치마크
- IoT 자동 캡처

### 1.5 권한 매트릭스 (v0.1)

| 영역 | 권한 |
|---|---|
| 학원 모든 lecture / video / material | view, create, update, delete, manage |
| youtube_channel | manage (OAuth 연결 / 정책 설정) |
| trust_relationship | manage (강사에게 grant 부여) |
| user (강사 초대) | create, update, delete |

상세는 [`auth-and-policy.md`](auth-and-policy.md).

## 2. 강사 (Teacher)

> 수업을 진행하고 데이터를 입력하는 주체. 본 제품의 **입력 핵심**. 강사 입력 노동이 30분 안에 가치로 회수되어야 한다 (명제 #1, #8).

### 2.1 기본 프로필

| 항목 | 내용 |
|---|---|
| 역할 | 강사 (학원 소속) |
| 권한 | `TEACHER` — 본인 강의·자료. directorGrant 시 확장 |
| 주요 접점 | Vite SPA (강사 화면, 모바일 브라우저 우선) + 카카오 알림톡 |
| 멀티 학원 | MVP는 1 강사 = 1 학원. 멀티 학원은 v0.5+ |

### 2.2 Jobs-to-be-Done

1. **수업하면 영상이 자동으로 만들어진다** — 영상 제작 노동 0 (v0.1)
2. **본인 강의가 YouTube 포트폴리오로 평생 남는다** (v0.1)
3. **본인 콘텐츠가 학생들에게 얼마나 다시 찾아지는지 안다** (RAG 참조 — v1.0)
4. **본인 평점 피드백 (익명)** (v1.0)
5. **사전 자료를 올려두면 영상 품질이 올라간다** (v0.1, 옵션)
6. **1-tap 출결로 입력 부담 최소화** (v0.5)
7. **본인 KPI 가 어떻게 계산되는지 투명히 본다** (v1.0)

### 2.3 페인포인트

| # | 문제 | 심각도 |
|---|---|---|
| 1 | 수업 후 자료 정리·업로드 부담 | Critical |
| 2 | 본인 강의가 "평가받는" 부담 | High |
| 3 | 강의 기록이 사라짐 (이직 시 포트폴리오 부재) | High |
| 4 | 카톡 알림에 묻혀 학원 공지 누락 | Medium |
| 5 | 출결 입력 작업 반복 | Medium |
| 6 | 학생들이 본인 강의를 잘 따라오는지 모름 | High |

### 2.4 Needs (Phase 별)

**v0.1 MVP**
- 강의 오디오 업로드 (drag&drop, 메타: 학원/반/날짜)
- 자료 옵션 업로드 (RAG seed — PDF, image, text)
- 본인 영상 publish 상태 조회
- 영상 검수 요청 (수동 검수 default)
- directorGrant 받은 강사: 자동 publish 가능

**v0.5**
- 1-tap 출결 입력 (모바일 우선)
- 본인 콘텐츠 RAG 분석 ("내가 어떤 개념을 자주 가르치나?")
- 본인 자료 라이브러리 OCR 검색

**v1.0**
- 본인 평점·코멘트 조회 (모더레이션 후, 익명)
- 본인 KPI 5축 시뮬레이션
- 스케줄 픽스 요청 (학원장에게 1-click)
- 본인 강의 → RAG 참조 횟수 가시화
- 본인 영상 YouTube 조회수 누적

**v2.0+**
- Android 앱 1-tap 수업 시작 (자동 녹음·판서 캡처·업로드)
- 본인 채널 (학원 내 부채널) 운영 옵션

### 2.5 권한 매트릭스 (v0.1, 기본)

| 영역 | 권한 (본인만) | directorGrant 시 확장 |
|---|---|---|
| 본인 lecture / material | view, create, update, delete | + 타강사 lecture view (`view_all_lectures`) |
| 본인 youtube_video | view, request_publish | + 자동 publish (`auto_publish_own`) |
| 타강사 lecture / material | (X) | view 가능 |
| youtube_channel | (X) | (X) — 학원장 only |

상세는 [`auth-and-policy.md`](auth-and-policy.md).

## 3. 학생 (Student)

> 수업을 듣고 영상으로 복습하는 주체. **MVP 직접 사용 X — 학부모 알림톡에 포함된 YouTube 링크로 영상만 시청**. v1.0 부터 RAG 채팅 직접 사용.

### 3.1 기본 프로필

| 항목 | 내용 |
|---|---|
| 역할 | 학생 (초·중·고생 다수, 중1~고3 = 12~19세) |
| 권한 | `STUDENT` (v1.0+) |
| 주요 접점 | YouTube 학원 채널 (v0.1, 로그인 불필요) → Vite SPA (학생 채팅, v1.0+) + 카카오 알림톡 |
| 연령대 주의 | 만 14세 미만은 법정대리인 동의 필수 |

### 3.2 Jobs-to-be-Done (v1.0+)

1. **"오늘 뭐 배웠지?"를 AI에게 묻는다** — RAG 채팅 즉시 답변 + 영상 링크
2. **수업을 영상으로 다시 본다** — YouTube 썸네일 → 모달 시청
3. **강사를 익명으로 평가한다** — 별점 1~5 + 짧은 코멘트
4. **시험 전에 학기 영상을 정주행한다** — 단원별 영상 모음
5. **모르는 개념을 그래프에서 찾는다** — Neo4j 개념 관계 시각화

### 3.3 페인포인트

| # | 문제 | 심각도 |
|---|---|---|
| 1 | 수업 빠지면 따라잡기 어려움 | Critical |
| 2 | 강사가 빨라서 못 따라감 | High |
| 3 | "이차함수 정점 어느 수업이었지?" 검색 안 됨 | High |
| 4 | 강사 평가할 채널이 없음 | Medium |
| 5 | 카톡방 시끄러워서 자료 못 찾음 | High (RAG 해결) |

### 3.4 Needs (Phase 별)

**v0.1 MVP** — *앱 직접 사용 없음, 단 DB에 등록됨*
- `student` 테이블에 학원장/강사가 등록 (이름, 반, 학부모 연락처, PIPA 동의)
- 학원 YouTube 채널에 publish 된 영상 시청 (로그인 불필요)
- 학부모를 통해 영상 링크 알림톡으로 전달받음 (`lecture.class_group → student → parent_phone`)

**v1.0**
- 학생 RAG 채팅 (ChatGPT 스타일)
- YouTube 모달 시청 (앱 떠나지 않음)
- PDF / SRT 다운로드
- 익명 강사 평점 (`teacher_review`, 모더레이션 후 강사에게 표시)
- 본인 평가 결과 조회

**v1.5~v2.0**
- 단원별 영상 자동 큐레이션 (시험 범위)
- 개념 그래프 시각화 (D3.js)
- 학습 약점 자동 진단 (질의 패턴 분석)

### 3.5 권한 매트릭스 (v1.0+)

| 영역 | 권한 |
|---|---|
| `youtube_video` (본인 수강) | view (public/unlisted) |
| `youtube_video` (타 수업) | view (public만) — 학원 정책 따름 |
| RAG 채팅 (학원 RAG) | query (질의 → `rag_query_log` 저장) |
| RAG 채팅 (글로벌 RAG) | (X) — v2.0+ 학원장 정책 |
| `teacher_review` 작성 | create (익명, 본인 수강 강사만, 월 1회) |
| `teacher_evaluation` 집계 | (X) — 강사·원장만 |

### 3.6 학생 사용 한도 (v1.0)

- 일 30 질의 (기본, 학원장 조정 가능)
- 월 500 질의 (소프트 한도)
- 부적절 질문 거부 응답 (LLM-as-judge)
- 답안 직접 제공 정책상 제한 (학원 인가 시만)

## 4. 학부모 (Parent)

> 자녀 학원 활동의 감시·결제 주체. 본 제품은 **앱을 깔지 않는다**. 카카오 알림톡 + YouTube 링크로 모든 가치를 전달. v1.0 부터 PWA β 옵션 추가.

### 4.1 기본 프로필

| 항목 | 내용 |
|---|---|
| 역할 | 학부모 (자녀 학원생) |
| 권한 | (별도 회원 X, v0.1) — 알림톡 수신만. v1.0+ PWA β |
| 주요 접점 | 카카오 알림톡 (영상 링크 포함) → YouTube 시청 → (옵션) 학부모 PWA |
| 연령 | 자녀 만 14세 미만 시 법정대리인 동의 필수 |

### 4.2 Jobs-to-be-Done

1. **앱 안 깔고 카톡에서 자녀 수업 영상 시청** (v0.1)
2. **자녀가 뭘 배우는지 영상으로 확인** (v0.1)
3. **학원 신뢰도를 영상으로 판단** (v0.1)
4. **학원이 먼저 위험을 알려준다** (자녀 이탈 위험 — v1.0+)
5. **자녀 학습 인사이트 받는다** (월간 리포트 — v1.0+)

### 4.3 페인포인트

| # | 문제 | 심각도 |
|---|---|---|
| 1 | 자녀가 학원에서 뭘 배우는지 모름 | Critical |
| 2 | 학원 앱 깔기 부담 | Critical |
| 3 | 학원 정보가 카톡방에 묻힘 | High |
| 4 | 자녀 이탈 / 학습 부진 사후 인지 | High |
| 5 | 결제 / 출결 알림이 흩어짐 | Medium |

### 4.4 Needs (Phase 별)

**v0.1 MVP**
- 카카오 알림톡 (영상 link + 핵심 요약)
  ```
  [A학원] 김민서 학생 오늘 수업 영상
  📺 중3 수학 — 이차함수 정점
  핵심: y=ax²+bx+c 변환 5문제
  [영상 보기]
  ```
- YouTube 링크 클릭 → 모바일 앱 / 웹 (로그인 X)
- 자녀 등장 동의 (입학 시) — Phase 1 은 음성 위주, 카메라 모드는 Phase 2 부터

**v1.0**
- 학부모 PWA β (옵션)
  - 자녀 영상 큐레이션
  - 학원 채널 바로가기
  - 학습 인사이트 (자녀 약점 단원)
  - 자녀 등장 동의 토글

**v2.0+**
- 자녀 학습 약점 자동 진단
- 학부모 RAG (자녀 학습 질의 — 학원장 허용 시)
- 미동의 학생 모자이크 처리 영상

### 4.5 권한 / 데이터 정책 (v0.1)

- 알림톡 수신 (전화번호 필요, 학원장이 등록)
- 영상 시청 (YouTube 공개 정책 따름, 로그인 X)
- 클릭 추적 → `notification.read_at` 자동 기록
- 자녀 개인정보 접근 (X) — v1.0 PWA 도입 시 OAuth 등으로 분리 처리

## 5. 페르소나 간 가치 흐름

```
[강사]
  음성 업로드 → 영상화 자동
       │
       ▼
[학원장]
  영상 검수 + publish 결정 → 채널 자산 축적
       │
       ▼
[학부모]
  알림톡 (영상 링크) → YouTube 시청 → 학원 신뢰
       │
       ▼ (자녀에게 전달)
[학생]
  YouTube 영상 시청 (v0.1) → AI 채팅 복습 (v1.0)
       │
       ▼
[강사 평점 ← 학생]
[RAG 참조 → 강사 영향력 측정 → 강사 평가]
```

→ **4 페르소나가 한 데이터 사이클을 형성**. 한 면이 빠지면 다른 면의 가치도 줄어듦 = **4면 락인**.
