# 제품 비전

> 작성일: 2026-05-23
> Academy AI 가 누구에게 어떤 가치를 어떻게 전달하는지의 단일 진술.

---

## 1. 한 줄 비전

> **Academy AI 는 학원의 "운영 두뇌 + 미디어 공장 + 학습실" 3-in-1 플랫폼이다. 강사가 수업하면 데이터가 정돈되고, 영상이 만들어지고, 학원 채널이 자라며, 학생은 AI 채팅으로 그 자산을 다시 묻는다.**

---

## 2. 우리가 만드는 것

```
┌─────────────────────────────────────────────────────────┐
│                  운영 두뇌                              │
│  강사 KPI · 학생 360 · 학부모 알림 · 컴플라이언스          │
├─────────────────────────────────────────────────────────┤
│                  미디어 공장 ⭐ 핵심 차별점              │
│  수업 → STT → RAG 분석 → HyperFrames MP4 → YouTube       │
├─────────────────────────────────────────────────────────┤
│                  학습실                                 │
│  RAG 채팅 + 개념 그래프 + 영상 복습 + 강사 평가          │
└─────────────────────────────────────────────────────────┘
```

세 영역의 **공통 기반 = RAG 인프라 (Qdrant + Neo4j + Embedding)**. 모든 데이터가 한 곳에 모이고, 모든 가치가 그 위에서 생성됨.

## 3. 우리가 만들지 않는 것

| 영역 | 이미 잘하는 곳 | 우리의 입장 |
|---|---|---|
| 출결 / 수납 SaaS | 클래스업, ACA2000 | 무료 영역, 차별점 아님 |
| AI 학습 튜터 (B2C) | 콴다, 매쓰홀릭 | 학생 직접 답변은 정책상 제한 |
| 전자칠판 HW / LMS | 삼성, LG, 아하 | HW 종속 안 함 |
| 영상 편집 SaaS | 프리미어, CapCut | 자동 생성에만 집중. 수동 편집 미지원 |
| YouTube 채널 운영 SaaS | TubeBuddy, vidIQ | 학원 도메인 특화. 일반 채널 도구 X |

→ **학원장이 기존 도구를 그대로 쓰면서, 본 제품을 얹어 쓰는 형태** 가 기본 가정.

## 4. 시장 기회

| 영역 | 규모 |
|---|---|
| 한국 사교육 시장 | 29.2조 / 학원 9만 개 (2024 기준) |
| SAM (디지털 학원 관리 시장) | ~1.5조 |
| 5년 SOM 목표 | 750억 ~ 1,500억 (5%~10% 점유) |
| 학원 YouTube 채널 보유율 | < 5% (사실상 빈 시장) |

**핵심 인사이트:**
1. **학원 YouTube 채널 시장은 비어 있다.** 콘텐츠 제작 인력 부재가 본질적 원인 → 우리가 자동화로 해결.
2. **학원 영상 = 가장 강력한 신뢰 기반 마케팅 자산** (광고보다 효과 큼).
3. **공교육 AIDT 좌초** → 학원이 학습 데이터 주체로 부상하는 정책 기회.
4. **다지점·프랜차이즈 본사** 가 표준 운영 거버넌스 필요 → Enterprise 매출.

## 5. 진입 슬로건 (페르소나별)

- **학원장**: "강사 한 명이 영상 제작팀 10명입니다. 수업하면 학원 채널이 자랍니다."
- **강사**: "당신의 강의는 사라지지 않습니다. YouTube 포트폴리오로 평생 남습니다."
- **학생**: "오늘 수업 뭐 했어? AI에게 물어보세요. 영상까지 보여줍니다."
- **학부모**: "앱 깔지 마세요. 카톡에서 자녀 수업 영상 바로 보기."
- **본사·체인**: "30개 지점의 채널이 동시에 자랍니다."

## 6. 12 명제 (제품 의사결정 기준)

모든 신규 기능·화면은 아래 12 명제와의 정합성을 자가 검토한다.

### 운영 명제 (1~8)

1. **데이터 입력의 핵심은 강사다.** 강사 입력 노동이 30분 안에 가치로 회수되어야 함.
2. **문제는 데이터 부족이 아니라 연결되지 않는 구조다.**
3. **AI 는 나중에, 데이터 먼저.** Phase 1 은 축적, Phase 3 부터 판단.
4. **학원 내 데이터는 세세히 / 타 학원은 평균만.** RAG 격리 정책.
5. **MVP 의 핵심은 AI 자동화가 아니라 데이터 축적과 가시화.**
6. **Dashboard 는 KPI 화면이 아니라 운영 데이터 연결 상태를 보여주는 구조.**
7. **학원장의 시간이 가장 비싼 자원.** 모든 UI 는 학원장 시간을 줄이는 방향.
8. **데이터를 입력한 강사에게는 30분 안에 가치를 돌려준다.**

### 미디어 명제 (9~12)

9. **모든 수업은 영상이 된다.** 영상화되지 않은 수업 = 자산 누락.
10. **YouTube 채널은 학원의 자산이다.** 강사 개인이 아닌 학원 소유.
11. **RAG 는 학원 자산의 자연어 인터페이스다.** 검색·요약·복습의 단일 진입점.
12. **자동화의 마지막 1% 는 사람이 결정한다.** 영상 검수 / 공개 범위 / 자녀 등장 동의는 인간이 최종 결정.

## 7. 핵심 가치 제안 (페르소나별)

### 7.1 학원장
- **5분 안에 학원 상태 파악** (대시보드 — v0.5)
- **객관적 강사 평가** (5축 자동 산출 — v1.0)
- **학원 채널 자동 운영** (영상 검수 → publish — v0.1)
- **자연어 운영 질의** ("이번 달 약점 단원?" — v0.5)
- **학생 이탈 사전 감지** (v1.0+)
- **컴플라이언스 자동화** (v3.0+)

### 7.2 강사
- **수업 = 영상 = 포트폴리오** (v0.1)
- **본인 콘텐츠 영향력 가시화** (RAG 참조 횟수 — v1.0)
- **익명 평점 피드백** (v1.0)
- **자료 사전 업로드로 영상 품질 향상** (v0.1, 옵션)
- **1-tap 출결** (v0.5)
- **본인 KPI 투명성** (v1.0)

### 7.3 학생
- **수업 영상 YouTube 시청** (v0.1)
- **AI 채팅으로 학원 자산 자연어 질의** (v1.0)
- **개념 그래프 시각화** (v1.0+)
- **시험 전 누적 복습** (v1.0)

### 7.4 학부모
- **앱 안 깔고 알림톡 + YouTube 링크** (v0.1)
- **자녀 수업 영상 시청** (v0.1)
- **학원 신뢰도 영상으로 판단** (v0.1)
- **학습 인사이트 자동 알림** (v1.0+)

## 8. Phase 별 가치 누적

```
v0.1 MVP  ──→  영상화 자동화 + RAG 인프라 (강사 → 학원장 → 학부모)
v0.5      ──→  운영 두뇌 (학원장 자연어 질의 / 면담 prep / 5 P0 화면)
v1.0      ──→  학습실 (학생 RAG 채팅 / 강사 평가 / 학부모 PWA)
v2.0      ──→  Android 자동 녹음 / 글로벌 RAG / 본사 통합
v3.0+     ──→  Enterprise / 광고 수익 / 인접 시장
```

각 단계는 **이전 단계의 데이터·인프라 위에 쌓는다**. 건너뛰기 X.

---

## 9. 시장 기회의 시점

- **Now (2026)**: 학원 YouTube 채널 보유율 5% 미만. 콘텐츠 제작 부담이 진입 장벽.
- **3년 후**: 학원 영상 보유율 30~50% 예상. **선점 학원이 신뢰·등록률에서 압도적 우위**.
- **공교육 AIDT 좌초** 가 학원으로의 데이터 주도권 이전을 가속.

→ **지금 진입하지 않으면 3년 후 따라잡기 어렵다.**
