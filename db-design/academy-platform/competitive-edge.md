# 차별화 및 경쟁 우위

> 작성일: 2026-05-23
> "왜 일반 학원 SaaS / ERP / LMS 와 다른가" 의 단일 진술.

---

## 1. 한 줄 차별화

> **일반 학원: 수업이 끝나면 사라진다. Academy 학원: 수업이 끝나면 영상이 되고, 채널이 자라고, RAG 가 답한다.**

이게 우리가 일반 학원 SaaS, ERP, LMS 와 다른 단 한 가지.

---

## 2. 풀 파이프라인 (4-Phase 자동화)

```
┌────────────────────────────────────────────────────────────┐
│  Phase A: 수업 (Capture)                                   │
│  강사 음성 업로드 (v0.1) → Android 자동 녹음 (v2.0)         │
├────────────────────────────────────────────────────────────┤
│  Phase B: 변환 (Transform)                                 │
│  Google STT + Google Vision (OCR, v0.5+)                   │
│      ↓                                                     │
│  Claude API ── 비디오 스크립트 (SRT)                        │
│              ── PDF 강의노트                                │
│              ── 썸네일 텍스트                                │
│              ── Neo4j 개념·관계 추출                         │
├────────────────────────────────────────────────────────────┤
│  Phase C: 영상화 (Publish)                                 │
│  Google TTS Neural2 ko-KR (한국어 나레이션)                 │
│      ↓                                                     │
│  HyperFrames API (HTML + GSAP → MP4)                       │
│      ↓                                                     │
│  YouTube Data API v3 → 학원 채널 업로드                    │
├────────────────────────────────────────────────────────────┤
│  Phase D: 복습 (Consume)                                   │
│  학생 RAG 채팅 (v1.0) — Qdrant + Neo4j                     │
│      ↓                                                     │
│  rag_query_log 누적 → 자주 묻는 약점 → 콘텐츠 보강 힌트       │
└────────────────────────────────────────────────────────────┘
```

각 Phase 는 **별도 워커 job 으로 분리**, 실패 시 재시도 가능 (idempotent).
상세는 [`pipeline.md`](pipeline.md).

## 4. Moat — "왜 따라잡기 어려운가"

### 4.1 데이터 복합도

학원 RAG = **5중 데이터** 의 융합:
- STT (강사 발화)
- OCR (판서 — v0.5+)
- 영상 (YouTube 메타 + 조회수 + 댓글)
- 평점 (학생 익명 평가)
- 출결·학생 상태

→ 경쟁사가 출결만 있는 데이터로는 RAG 가치 X. 데이터 축적 ≠ 정돈된 데이터.

### 4.2 영상 제작 비용 곡선

| 방식 | 영상 1편 비용 | 비고 |
|---|---|---|
| 일반 학원 외주 | 30~50만원 | 한 학원 월 N편 = 수백만원 |
| 자체 편집 (강사 직접) | 시간 비용 ↑ | 강사가 본업에 집중 못함 |
| **Academy 자동화** | **~5,000원 이내** | HyperFrames + Claude + YouTube API |

→ **100배 비용 절감**. 강사 한 명이 영상 제작팀 10명 효과.

### 4.3 채널 효과 (Network Effect)

```
채널 영상 누적
    ↓
SEO + 구독자 증가
    ↓
신규 학생 등록 (영상 → 학원 신뢰)
    ↓
수업 데이터 증가
    ↓
RAG 정확도 증가
    ↓
학생 만족도 증가
    ↓
채널 추천·재등록
    ↓
영상 누적 (양방향 플라이휠)
```

→ **데이터·채널·등록률 3축이 서로를 강화**. 시간이 갈수록 격차 확대.

### 4.4 4면 락인 (Multi-sided Lock-in)

```
학원장 (운영 가치)
    ─ 객관 KPI / 마케팅 자산 / 자연어 질의
강사 (포트폴리오 가치)
    ─ YouTube 채널 / 평점 / 콘텐츠 영향력
학생 (학습 가치)
    ─ RAG 채팅 / 영상 복습 / 개념 그래프
학부모 (관찰 가치)
    ─ 알림톡 + 자녀 영상 / 학습 인사이트
```

기존 학원 SaaS 는 학원장 중심 단일 락인 (한 면). Academy 는 **4면 동시 가치** → 한 면이 빠져나가도 다른 면이 잡아줌.

## 5. 신규 등록 Attribution 모델

```
학원 신규 등록 채널 비중 (가설)
  ├─ 지인 추천         40% (기존)
  ├─ YouTube 채널 ⭐    25% (Academy 효과)
  ├─ 학원 홈페이지     15%
  ├─ 광고              10%
  └─ 기타              10%
```

**검증 방법**:
- 입학 폼에 "어떻게 알게 됐나요?" 필수 입력
- 6 개월 attribution 추적
- YouTube attribution ≥ 15% 달성 시 가설 검증

→ 학원장 의사결정에서 **영상 ROI 가 측정 가능한 첫 번째 SaaS**.

## 6. 학원장 의사결정 비용 변화

| 결정 | Before | Academy |
|---|---|---|
| 강사 인센티브 산정 | "감각" + 부분 KPI | 5축 종합 데이터 (v1.0) |
| 마케팅 예산 집행 | 광고 효과 추정 | YouTube attribution 실측 (v1.0+) |
| 신입 강사 채용 | 인터뷰 + 시강 | 후보 강사 YouTube 채널 사전 검증 |
| 콘텐츠 보강 우선순위 | 감각 | RAG 질의 로그 → 약점 단원 자동 식별 (v0.5) |
| 학생 면담 prep | 30~60분 수기 정리 | RAG 자동 prep (v0.5) |

→ **모든 결정이 데이터 기반**으로 이동.

## 7. 시장 진입 우위 (시점 분석)

| 항목 | 현재 (2026) | 3년 후 (2029) |
|---|---|---|
| 학원 YouTube 채널 보유율 | < 5% | 30~50% 예상 |
| 학원 SaaS 시장 영상화 기능 | 0개 (Academy 만) | 다수 진입 예상 |
| RAG 기술 성숙도 | 안정화 단계 (2025+) | 일반화 |
| 학부모 YouTube 채택률 | 시청 시간 압도적 (이미) | 더 증가 |

**핵심 인사이트:**
- **선점이 영구 우위**: 학원이 YouTube 채널을 보유하면 검색·SEO 효과로 신규 등록률 ↑. 따라잡기 어려움.
- **공교육 AIDT 좌초** 가 학원으로 데이터 주도권 이전을 가속.
- **3년 후 진입은 늦다.** 지금이 진입 시점.

## 8. 우리의 약점 (정직)

| 약점 | 대응 |
|---|---|
| HyperFrames 단일 의존 | 협상 + v2.0 자체 렌더링 R&D |
| YouTube TOS 정책 변경 리스크 | AI 콘텐츠 명시 + 검수 default + 백업 채널 |
| 학원 가입 마찰 (OAuth + 강사 초대 + 자료 업로드) | "5분 onboarding" 목표 + 데모 영상 자동 생성 |
| 강사 채택 저항 (평가 부담) | 익명 평점 + trust 자율성 + 본인 검수 |
| 한국어 STT 정확도 (수학 전문용어) | Google STT custom vocabulary + 강사 수정 UI (v0.5+) |
| Android 의존 (v2.0) | MVP 는 강사 수동 업로드로 분리 |

상세는 [`risks.md`](risks.md).

## 9. 차별점이 ❌ 가 되는 시나리오

> 우리의 차별점이 무력화되는 경우를 직시.

| 시나리오 | 대응 |
|---|---|
| YouTube 가 학원 채널 자동 업로드 금지 | 백업 채널 + 자체 호스팅 옵션 (v3.0+) |
| HyperFrames 서비스 중단 | 대체 vendor + 자체 FFmpeg 렌더 (v2.0~) |
| 경쟁사가 1년 안에 동일 기능 출시 | 학원 30+ 선점 + 데이터 누적 (양방향 플라이휠) |
| 학원장이 영상 publish 자체에 거부감 | unlisted 모드 + 직접 학부모에게 링크 (검색 노출 X) |
| PIPA 강화로 학생 음성 처리 불가 | 본인·법정대리인 동의 + 모자이크 처리 파이프라인 (v2.0+) |

## 10. 한 줄 요약

> **수업의 가치를 영구 자산화하는 SaaS**. 시간이 갈수록 학원의 마케팅·운영·학습 자산이 누적되며, **데이터·채널·등록률의 양방향 플라이휠** 이 다른 학원과의 격차를 벌린다.
