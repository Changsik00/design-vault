# Design Vault

AI agent 와 나눈 요구사항 분석, 설계 수렴, 아키텍처 결정 내용을 기록하는 개인 설계 보관함.

## 구조

```
design-vault/
  db-design/        # 데이터베이스 설계 요구사항 분석
  architecture/     # 시스템 아키텍처 설계 논의
  auth/             # 인증/인가 설계
  api-design/       # API 설계
```

## 기록 원칙

- 질문한 요구사항과 AI의 답변/분석을 함께 기록
- 결정된 방향과 그 이유를 명시
- 날짜와 컨텍스트를 함께 남김
